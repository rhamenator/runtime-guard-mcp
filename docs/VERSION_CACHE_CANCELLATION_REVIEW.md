# Versioning, discovery, caching and cancellation review

Self-review against upstream commit `271ecc9accafdd9b83a3c869fa67c22953b2af80`, 2026-10-23. Exact source hashes/links are in CORE_CONFORMANCE_INVENTORY.md. This classifies the implemented surface and remaining limits; it is not full MCP certification or independent release approval.

| ID | Server obligation / applicability | Code and evidence / disposition |
| --- | --- | --- |
| V01 | Reject unsupported per-request versions with supported/requested data | Handler returns -32022; installed version/cache probe checks discovery/list/ping retry recovery and supported-list consistency. |
| V02 | Implement server/discover; do not require it before other RPCs | Installed first inline tools/list version failure, then discovery; earlier direct tool-call/SDK probes cover discovery-free dispatch. Discovery includes capabilities, server identity and actual supported revisions. |
| V03 | Validate extension identifiers/settings; fall back to core or reject unsupported extensions | Capability validator enforces prefixed identifiers and object settings. Installed unknown-extension list/call requests execute core behavior; no extensions are advertised. Per-extension semantics must be implemented before advertising one. |
| V04 | Dual-era selection and concurrent compatibility | Installed sequence interleaves legacy initialize/list with modern requests and malformed modern metadata. Modern context never inherits; supported legacy revisions require their initialize-based grammar. A legacy version appearing in discovery does not advertise modern metadata semantics for that revision. |

| C01 | Complete cacheable results carry nonnegative integer TTL and scope | Only discovery and tools/list are implemented cacheable operations. Installed probes check ttlMs=0/private in full and operator-filtered configurations. Other cacheable primitives are conditional on adding them. |

| C03 | Hints do not replace primitive access controls | Installed filtered-tool request rejects despite a client claim of cached tool authority. Client-supplied cache hints cannot alter server ttlMs/private scope. Operator tool selection/auth remain the actual boundary. |
| C04 | Cache keys, authorization separation, retries, freshness and polling/backoff | CLIENT obligations; the server supplies hints and does not cache client results. No client-cache certification is claimed. No listChanged/subscription feature is advertised. |

A writing frame cannot be retracted, Python policy work is not preempted and committed effects do not roll back. | X05 | Sent-request timeout/progress handling and UI/reason logging | No outbound RPCs exist, so sender timeout/progress policies and UI behavior are outside this server surface. Raw cancellation reasons are deliberately not logged to preserve data minimization; this recommendation departure belongs in human review. Test controllers have finite deadlines; they do not certify arbitrary client timeout configuration. |

## Reproduce and limits

Run `python scripts/version_cache_review.py /path/to/server/bin/runtime-guard-mcp`. The isolated installed stdio campaign checks 32 replies across full/four-tool and filtered/one-tool configurations, private zero-TTL hints, unsupported-version recovery, unknown-extension core fallback, disabled-tool denial and legacy/modern interleaving. The shared installed-frame helper accepts an optional operator config; defaults used by prior probes are unchanged. CI repeats this on Python 3.11–3.14.

Existing cancellation_metadata_review.py, queued_cancellation_review.py and output_backpressure_review.py cover installed reader/worker, delivery/discard and stalled-reader behavior. Real Codex/Cursor CLI cancellation limitations remain documented in MODERN_CONFORMANCE.md; this review does not fix those clients. Native-platform, final exact candidate/client/adversarial/resource/package/provenance and independent human approval remain release gates. REQUEST_CONTEXT_REVIEW.md additionally documents process-local state portability and the single-owner trust boundary.
