# Work instructions

Read only the relevant source, tests, and docs for the task. Use narrow `rg` searches and bounded command output; avoid dumping entire repositories or repeated test logs. Reuse the existing policy and MCP helpers and prefer the standard library. Add a third-party runtime dependency only for a concrete security or reliability gap that cannot be addressed well in the existing stack; record the tradeoff in `docs/dependencies.md`. Run focused tests while editing, then the full standard-library suite once before finishing. Report actual coverage and limits; these tools are advisory unless a host routes actions through them.
